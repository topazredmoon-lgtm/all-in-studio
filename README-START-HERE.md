# All-in-keep: the one folder that survives the reset

Built 2026-10-13. Everything the All-in project needs to run, and nothing else.

## Start in 3 steps
1. In Claude: **new project -> choose folder `C:\Users\pc\Documents\All-in-keep\All-in`**.
2. In a terminal for that project: `. C:\Users\pc\Documents\All-in-keep\env.ps1` (sets the voice paths, UTF-8, offline Hugging Face).
3. First message of every session: *"Read HANDOVER.md, then PLAYBOOK.md and CLAUDE.md, continue."*

## What was NOT carried over (on purpose)
- `.render-tmp` (2.6 GB of render scratch), `.remotion` cache, `engine` caches: regenerated by the next render.
- `.cc-src` raw source talks (593 MB, were never in git): `bash scripts/redownload-sources.sh`. The 58 tracked transcript files of it **are** restored.
- `.removed-news-clips`: news clips removed under the MONEY RULE. Not kept, by design.
- Regenerable bulk of the old projects (SCRATCH HOLY `.cache\bundles` 11 GB, `qa\stills` 3.4 GB, tools; jolly-bell Remotion bundles, caches and ~3.5 GB of narration wavs / raw news-clip downloads): see `_legacy\NOT-CARRIED.md` for the exact list. Their *unique* work (untracked and uncommitted files, finished films) **is** in `_legacy\`.

## Changes made to the copy (the original is untouched until you run the wipe)
- `CLAUDE.md` / `HANDOVER.md`: new paths + a **Quota guardrails** block (max 2 subagents, Sonnet default, stop on 429, no auto-retry or scheduled check-ins, new session past ~150k tokens).
- `tools/tts.py`: Kokoro model folder now defaults to `..\voice\kokoro-models` (still overridable with `KOKORO_MODELS`).
- `.claude/settings.json`: `model: sonnet`, subagents on Sonnet, asks before `git push` / destructive commands, no remote/cloud MCP tools.
- Nothing was committed or pushed. `git status` shows your 83 pending changes plus these edits.

## The wipe (you run these; both are dry-run by default)
1. `.\1-WIPE-OLD-PROJECTS.ps1` then `.\1-WIPE-OLD-PROJECTS.ps1 -Execute`  (old project folders)
2. Quit Claude fully, then from a plain PowerShell: `.\2-RESET-CLAUDE-APP.ps1 -Execute`  (app state, sessions, memory, mods)

## Online leftovers that a local wipe does NOT remove
The post-reset quota drain came from the cloud side. On claude.ai, before starting the new project:
- archive or delete the 9 cloud sessions and the ~30 offline Remote Control sessions,
- delete the project channel thread that keeps waking sessions,
- check Settings for any routine named `limit_wake ...` or "Check-in" and remove it,
- keep Remote Control **off** for the new project.
