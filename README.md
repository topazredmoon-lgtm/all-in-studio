# All-in

The merged explainer-video studio: the **Signal** design system from "disgn systems" as the base, the best script and clips from
**not-so-dark-times**, the v23 film's split-screen layout and paper evidence from **jolly-bell** (the "joli takeover"), and HOLLYSCRATCH's working habits. Source projects are read, never modified.

Read first: `design-system/DESIGN.md` (the system), `design-system/VISUALS.md` (every visual made so far), `design-system/LEARNINGS.md` (what review taught), then `HANDOVER.md`.

## Layout

| Path | What |
|---|---|
| `design-system/` | DESIGN.md (spec), VISUALS.md (catalogue), LEARNINGS.md (log). Updated after every video and every review. |
| `engine/src/ds/` | The system in code: `tokens.ts`, `core.tsx` (primitives + word sync), `layouts.tsx` (split, full, chapter, clip) |
| `engine/src/visuals/<topic>.tsx` | Visuals generated for one topic, built from `ds/` only |
| `engine/src/videos/<id>/timeline.json` | Generated by `tools/build.py` |
| `engine/public/` | Fonts, textures, the topic's photos and clips |
| `videos/<id>/` | `gen_script.py` → `script.json`, `audio/` (voiced lines + word timings), `SOURCES.md`, `qa/`, `out/` |
| `assets/music/` | Generated, licence-free music beds (from HOLLYSCRATCH) |
| `tools/` | `build.py` (timeline + mix), `stills.mjs` (review sheet), `render.mjs` (final mp4), `tts.py` (Kokoro voice), `sfx.py`, `watch.py` |

## Make a video

```bash
python videos/<id>/gen_script.py                 # words + shots -> script.json
python tools/tts.py <id>                         # voice (cached per line; needs kokoro_onnx + faster_whisper)
python tools/build.py <id>                       # timeline + master.wav
node tools/stills.mjs <id> 0.85                  # one still per beat -> videos/<id>/qa/sheet_85.jpg (look at it)
node tools/render.mjs <id> --concurrency=6       # -> videos/<id>/out/<id>_vN.mp4
```
(`engine/`: `npm ci` once. Paths contain spaces: quote them.)

## Cloud sessions (Linux)

Rules for every session are in `CLAUDE.md`. One-time setup on a fresh Ubuntu/Debian box:

```bash
bash scripts/cloud-setup.sh      # apt deps, git lfs pull, npm ci, Remotion's Chrome, .venv, Kokoro + Whisper models
source .cloud-env.sh             # PYTHONIOENCODING, HF_HUB_OFFLINE, KOKORO_MODELS, .venv on PATH
bash scripts/redownload-sources.sh   # only when cutting new clips: raw source talks into .cc-src/
```

**What is in git:** code, tools, design system, playbook, handover, every video's scripts, `SOURCES.md` and
`LICENCES.md`, voiced lines and word timings, the cut clips the engine renders from (`engine/public/`), music,
and the delivered cuts (`All-in_captchas_3min_v6.mp4`, `All-in_captchas_full_v3.mp4`, the AI black markets sample).
All media goes through **Git LFS**.

**Left out on purpose:** full-quality renders (300-470 MB each; re-render with `tools/render.mjs`), `master.wav`
mixes (`tools/build.py` rebuilds them), render scratch (`.render-tmp/`, `videos/*/tmp/`, stills), the raw source
talks in `.cc-src/` (~560 MB; URLs kept in `.cc-src/urls.txt`, `.cc-src/ccc.txt`, `.cc-src/aibm/urls.txt` and
each video's `LICENCES.md`), the Windows Chrome in `.remotion/`, `node_modules`, and the news clips removed under
the money rule (`.removed-news-clips/`, never to be used).

**Limits in the cloud:**
- Needs network access for apt, npm, PyPI, the Kokoro release on GitHub (~310 MB), the Hugging Face Whisper model,
  media.ccc.de / Wikimedia downloads and Git LFS. No paid API keys are used anywhere.
- No GPU: Whisper runs `small.en` on CPU (the PC uses `large-v3-turbo` on CUDA), so transcription is slower and a
  little less precise; renders are CPU-only and slow, so check stills before any full render.
- `tools/sheet.py` uses Arial on Windows and PIL's default font elsewhere (contact-sheet labels only).
- The PC keeps the Kokoro models outside the repo; in the cloud `tools/tts.py` reads `KOKORO_MODELS`.
- Untested on Linux so far: the first cloud session should run the setup script and fix what breaks.
