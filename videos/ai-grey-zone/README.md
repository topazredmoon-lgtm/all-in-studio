# AI's Grey Zone — script draft

An original, research-led All-in topic about the science behind modern AI security attacks: prompt jailbreaks, indirect prompt injection, and training backdoors.

## Scope

- Focuses on methods and underlying mechanisms, plus the difference between authorized testing and harmful misuse.
- Uses current primary research, including an April 2026 arXiv preprint, with its limitations stated in the narration.
- Avoids actionable payloads, exploit code, data-theft steps, and claims that models are sentient or secretly plotting.
- This topic is distinct from the retired AI black markets film: it covers AI security methods and their science, not criminal marketplaces.
